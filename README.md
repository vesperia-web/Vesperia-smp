# Vesperia SMP Web Portal

## 🚀 Как запустить

1. **Установите Node.js**.
2. В папке проекта запустите:
   ```bash
   npm install
   npm run dev
   ```

## 🛠 Исправление ошибки "Вы замьючены"
Если сайт пишет, что вы не можете создавать темы:
1. Откройте файл `SUPABASE_SETUP.sql` в этой папке.
2. Скопируйте его содержимое.
3. Зайдите в **Supabase Dashboard** -> **SQL Editor**.
4. Вставьте код и нажмите **RUN**.

## 🔑 Вход через Discord
Главная кнопка теперь ведет в Discord канал. Чтобы войти в аккаунт на сайте, используйте кнопку **"Войти"** в правом верхнем углу (в навигации).
